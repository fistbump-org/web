Wallet Desktop + mobile · Swift

Fistbump Wallet

Manage FBC, register names, bid on auctions, and configure DNS records. Includes a built-in full node. Ships for macOS, Windows, Linux, Android, and iOS.

Download Source

fbd Full node · Swift

fbd — Fistbump daemon

The reference full node. Validates the chain, participates in P2P, serves authoritative DNS from chain state, and includes a wallet and miner. Controlled via fbdctl over JSON-RPC.

Download Source

Extension Browser · WebExtension

Browser extension

Adds a window.fistbump API to web pages so they can request signatures and send transactions through your desktop wallet. Talks to the wallet over native messaging — no HTTP, no open ports.

Chrome Web Store Firefox Add-ons

Swap Atomic · Non-custodial

Atomic Swap (FBC ↔ BTC)

Swap FBC and BTC directly, peer to peer, with no middleman. Both sides lock funds into hash time-locked contracts on their respective chains. Either both claims succeed or both refunds succeed — nothing in between is possible.

Open Swap Source
